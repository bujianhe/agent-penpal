⚠️ **这是危险操作。** 用 `agent-penpal` skill 的「链接泄漏了怎么办」。

## 第 1 步：先复述代价，等用户明确确认

复述这四条，然后**停下来等确认**：

- **老链接立即失效**（relay 上老路由没了）
- **所有对端都要换新名片**——他们存的旧名片/名册条目全部连不上
- daemon 重启，**正在跑的窗口会中断**
- 对话窗口的 **agentid 不变**（重启后能续聊）

## 第 2 步：用户确认后才执行

```bash
node <skill目录>/scripts/setup.mjs --rotate --confirm
```

**没有拿到确认之前，绝对不要执行这条命令。**

## 第 3 步：把新名片给用户

轮换完脚本会打印新名片，**原样转给用户**，让他转给所有对端。

---

**如果用户只是想换模型、不是换身份**：那不该用这个命令——模型问题用 `switch-model.mjs`（见 SKILL.md「给已有窗口换模型」），它不动 LINK / AGENT。
